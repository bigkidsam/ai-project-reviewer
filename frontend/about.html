How It Works

Understand the multi-stage analysis pipeline, static analyzers, and intelligent scoring model.

🔄 8-Stage Analysis Pipeline

1
Repository Fetch & Unpack
Clones public GitHub repositories with depth=1 shallow clone, or decompresses uploaded ZIP/TAR archives securely in sandbox directories.
2
Discovery & Filter Gate
Discovers supported code files (Python, JS, TS, Java) while automatically pruning virtual environments, node_modules, cache dirs, and binaries >250KB.
3
Multi-Tool Static Analysis
Runs AST syntax parser as an immediate gate, followed by Pylint, Bandit, Radon, ESLint, and Semgrep security checkers in parallel.
4
Metrics Aggregation
Aggregates findings into severity counts (critical/high/medium/low), categories (security/bug_risk/maintainability/style), and issue density per file.
5
8-Category Weighted Scorecard
Computes weighted scores spanning Code Quality (20%), Architecture (15%), Documentation (10%), Security (15%), Performance (10%), UI/UX (10%), Innovation (10%), and Testing (10%).
6
Tiered Fix Suggestions
Generates deterministic rule-based code replacements for frequent issues (unused imports, missing timeouts) and flags complex bugs for model guidance.
7
AI Summary Synthesis
Sends aggregated findings to Google Gemini for a natural-language executive summary, key risks, and architectural takeaways with rule-based fallback.
8
Self-Learning Quality Classifier
A local Scikit-Learn Random Forest model predicts quality classification and auto-retrains asynchronously on new reviews.

🚨 Severity Weighting & Impact

SeverityPrefix / CodePenalty WeightImpact Definition
CriticalFatal (F)10 ptsFatal execution bugs, syntax corruption, unparsable AST
HighError (E)7 ptsUndefined variables, import failures, critical logic flaws
MediumWarning (W)3 ptsUnused variables, missing HTTP timeouts, bad exception handling
LowConvention (C, R)1 ptFormatting inconsistencies, refactoring recommendations, docstrings

Quality Score formula: Score = max(0, 100 - Σ(severity_count × weight))
